## 📝 Content Writing Tips

### Hero Section
- **Greeting:** Keep it simple ("Hello, I am" / "Hi, I'm")
- **Name:** Your full name
- **Roles:** 3-5 roles that describe you, will rotate automatically
- **Tagline:** One powerful sentence about what you do

### About Section
- **Bio:** 2-3 paragraphs about your background, expertise, passion
- **Highlights:** 3-5 key achievements or strengths
- Keep it authentic and conversational

### Project Descriptions
- **Short:** 1-2 sentences for card preview
- **Full:** 3-4 paragraphs with problem, solution, results
- **Tech Stack:** List all major technologies used
- Include both GitHub and live URLs if available

### Experience Descriptions
- Use action verbs (Led, Built, Improved, Managed)
- Include quantifiable results (40% faster, 10+ projects)
- Focus on impact and achievements

## 🆘 Need Help?

**Issue:** Content not showing on website
**Solution:** 
1. Make sure you clicked **Publish** (not just Save Draft)
2. Refresh browser (Ctrl+Shift+R)
3. Check browser console for errors

**Issue:** Image not displaying
**Solution:**
1. Verify image uploaded successfully in Sanity
2. Check image is published
3. Try re-uploading image

**Issue:** Changes not reflecting
**Solution:**
1. Clear browser cache
2. Restart dev server: `npm run dev`
3. Verify `useCdn: false` in `web/sanity/client.ts`
